# 🧬 Particle Life Simulation (Artificial Chemistry - Pygame)

Une simulation fascinante de **chimie artificielle et d'émergence comportementale**, développée en **Python** avec **Pygame**. 

---

## 📸 Fonctionnalités

- 🧪 **Émergence de comportements complexes :** Des centaines de particules de 4 types différents interagissent selon une matrice de règles invisibles (attraction/répulsion), créant spontanément des structures semblables à des organismes vivants.
- 🎲 **Univers aléatoires infinis :** Appuie sur la touche `R` pour réinitialiser la simulation et générer instantanément de nouvelles lois chimiques, donnant naissance à de tout nouveaux motifs visuels.
- 🌐 **Espace infini (Tore) :** Les particules traversent les bords de l'écran pour évoluer dans un flux continu et fluide.
